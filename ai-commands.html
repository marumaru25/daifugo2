Claude 制限対策・自動再開
Claude Claude Auto-Continue
🌐 ブラウザ用（Chrome拡張）
claude.aiでツール使用上限に達したとき、「Continue」ボタンを自動でクリックしてくれる拡張機能。バックグラウンドタブでも動作するので、長い作業中に席を外しても止まらない。インストールするだけで有効。
chromewebstore.google.com/detail/claude-auto-continue/pmdfdcmdkocmfjjeflbhimdhafekbfei
Claude Code claude-auto-resume
💻 ターミナル用（シェルスクリプト）
Claude Codeが5時間の使用制限に達したとき、自動で待機してリセット後に再開してくれるスクリプト。一晩放置しても朝には作業が続いている。コーディングの長時間タスクに最適。
github.com/terryso/claude-auto-resume
Claude Code claude-auto-retry
💻 ターミナル用（自動リトライツール）
制限メッセージからリセット時刻を自動で読み取り、ちょうどそのタイミングで再開してくれる。「5時間後に再開」のような固定待機ではなく、正確なタイミングで動くのが強み。
cheapestinference.com/blog/claude-code-usage-limit-auto-retry
会話引き継ぎフレーズ（コピーして使う）
全AI共通 ハンドオフプロンプト
📋 制限が来る前に使う
会話が長くなってきたら、これを送ると次のセッションにそのまま引き継げる要約文を作ってくれる。制限でいきなり止まる前に早めに使うのがコツ。
全AI共通 会話再開フレーズ
📋 新しいセッションを始めるときに使う
ハンドオフプロンプトで作った要約をコピーして、新しい会話の最初にこのフレーズと一緒に貼り付けるだけ。前のセッションからスムーズに続きを再開できる。
ChatGPT 自動化ツール
ChatGPT ChatGPT Agent
🌐 ウェブ操作・外部アプリ連携
ブラウザ操作・フォーム入力・外部サービスへの実行を自律的にこなすエージェント機能。「このフォームを埋めて送信して」「このサイトから情報を取ってきて」などが可能。ChatGPT Plus以上で使える。
chatgpt.com → Agent機能をオン
ChatGPT Zapier × ChatGPT連携
🔗 9,000以上のアプリと自動連携
GmailやSlack・Notionなど9,000以上のアプリとChatGPTをつないで自動化できる。「新しいメールが来たら要約してSlackに送る」「フォームが送信されたら返信文を作る」などが可能。コード不要。
zapier.com/apps/chatgpt/integrations
Gemini 自動化ツール
Gemini Gemini Spark
📱 スマホのバックグラウンド自動実行
スマホがロック中でもクラウド上でGeminiがタスクを自動実行し続ける機能。「〇〇が起きたら通知して」「毎朝ニュースをまとめて」などをスマホが眠っている間も実行できる。Android向け。
gemini.google.com → Spark機能
Gemini Google Workspace自動連携
📧 Gmail・カレンダー・Docsと直接連携
GmailやGoogleカレンダー・Docsに直接組み込まれているので、別途ツールの設定不要。「このメールに返信して」「会議の議事録をDocsにまとめて」などをGoogleのサービス内で完結できる。
workspace.google.com → Gemini機能
⚠️ これらは公式コマンドではなく、SNS投稿者が独自に命名したプロンプト省略表現です。効果には個人差があります。
